## Student Tasks

1. **Construct the LCS dynamic programming table:**

2. **Find the Longest Common Subsequence:**
   By backtracking through the DP table, the Java program determines the exact string sequence common to both `AGGTAB` and `GXTXAYB`, which is **GTAB**.

3. **Determine the LCS length:**
   The length of the Longest Common Subsequence is **4**.

4. **Explain the importance of LCS in bioinformatics:**
   In bioinformatics, LCS is the foundational algorithm used to compare DNA, RNA, and protein sequences. Because mutations naturally cause insertions and deletions in genetic sequences over time, simple string matching fails. Finding the longest common subsequence allows scientists to identify the shared, evolutionarily conserved genetic structure between two organisms, revealing how closely related they are and identifying vital functioning genes.

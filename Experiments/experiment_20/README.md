# Experiment 20: 0/1 Knapsack Problem

## Output
```
Knapsack Capacity: 50
Maximum value: 220
```

## Explanation
The 0/1 Knapsack problem uses Dynamic Programming. An item can either be taken entirely or left (0/1 property). It builds a 2D array bottom-up, maximizing the total value for every sub-capacity without exceeding the weight limit.

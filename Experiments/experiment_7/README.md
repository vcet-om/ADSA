# Experiment 7: Implement Prim's Algorithm

## Output
```
Running Prim's Minimum Spanning Tree Algorithm:
Edge 	Weight
0 - 1	2
1 - 2	3
0 - 3	6
1 - 4	5
Total Cost: 16
```

## Explanation
Prim's Algorithm finds a Minimum Spanning Tree (MST) for a weighted undirected graph. It maintains a set of vertices included in the MST and greedily picks the edge with the minimum weight that connects a vertex in the MST to a vertex outside it.

# Experiment 16: Sum of Subsets Problem

## Output
```
Set: {10, 7, 5, 18, 12, 20, 15}, Target: 35
Subset found: [ 10 7 18 ]
Subset found: [ 10 5 20 ]
Subset found: [ 5 18 12 ]
Subset found: [ 20 15 ]
```

## Explanation
The Sum of Subsets problem uses backtracking to find all subsets of a given set of integers that sum to a specific target value. It explores the state space tree, discarding branches that exceed the target sum.

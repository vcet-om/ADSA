# Experiment 5: Implement Breadth First Search graph traversal

## Output
```
Following is Breadth First Traversal (starting from vertex 2):
2 0 3 1
```

## Explanation
Breadth First Search (BFS) algorithm traverses a graph level by level. It uses a Queue to keep track of adjacent vertices to visit next and a boolean array to ensure no vertex is processed more than once.

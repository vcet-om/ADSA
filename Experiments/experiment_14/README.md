# Experiment 14: Trie Data Structure

## Output
```
Inserted: apple
Inserted: app

Search 'app': true

```

## Explanation
A Trie (or prefix tree) is a tree-like data structure used to store a dynamic set of strings where keys are usually strings. It is highly efficient for string searching operations like auto-complete and spell-checking.

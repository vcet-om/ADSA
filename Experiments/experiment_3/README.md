# Experiment 3: Construct a binary tree from user inputs and perform Pre-order, In-order, and Post-order traversals

## Output
```
Simulating user input to construct the binary tree...
Pre-order traversal:
1 2 4 5 3 
In-order traversal:
4 2 5 1 3 
Post-order traversal:
4 5 2 3 1
```

## Explanation
This program constructs a Binary Tree (simulating user inputs) and demonstrates three Depth-First traversals recursively: Pre-order (Root-Left-Right), In-order (Left-Root-Right), and Post-order (Left-Right-Root).

# Experiment 1: Implementation of Merge Sort

## Output
```
Original array:
12 11 13 5 6 7 
Sorted array:
5 6 7 11 12 13
```

## Explanation
This code implements the Merge Sort algorithm, a divide-and-conquer approach. It recursively divides the array in half, sorts each half, and merges the sorted halves together.
